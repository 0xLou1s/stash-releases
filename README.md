# Stash for Mac: releases

Builds of [Stash](https://github.com/0xLou1s/stash), a private visual library for X posts.

**Download:** grab `Stash-<version>.zip` from the [latest release](https://github.com/0xLou1s/stash-releases/releases/latest),
unzip it, and move **Stash** to Applications.

Once installed, Stash updates itself: it checks `appcast.xml` in this repo once a day,
and you can check any time from **Stash › Check for Updates…**. Every update is signed,
and the app only installs ones signed with the Stash release key.
